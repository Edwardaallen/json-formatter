# JSON Formatter

A developer utility for formatting and validating JSON.

## Features

- JSON formatting
- JSON minification
- Syntax validation

## How to Use

Paste JSON and select Format or Minify.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Format valid nested JSON and review indentation.
- [ ] Minify the same JSON and verify the data remains equivalent.
- [ ] Enter malformed JSON and inspect the error message.
